## 1. Recap deck
- OA branding: teal, Montserrat, logo.
- One message per slide, with the takeaway in the title, big numbers and speaker notes.
- Running order: Title → At a glance (4 number tiles) → Rock scorecard → one slide per Rock → What we learned → Next quarter focus → next quarter's Rocks (overview + one slide each: why now, 3 actions, 3 measures with baseline).
- Count every product ("10 ways to buy"), not just the core VA offer.
- Never say "price" as a reason for no. Say "shopping and comparing".
- Save the deck where the user can open it (commit it if you're working in a git repo).

## 2. Per-Rock Notion report
Append it under the Rock page, or ask where it should live before creating a private page. Sections:
- Summary
- Why it mattered
- Results vs Definition of Done
- What we learned
- Next steps

## 3. Presenter script
About 6 minutes (about 800 words), timed per slide, simple language.

## 4. Next quarter's Rocks

- Create from the board's rock template: Status = In progress, Direct Responsible = Gail, Achieve By = end of quarter. Fill the 6 sections and the "How Sales Team Support Company Wide ROCKS" table.
