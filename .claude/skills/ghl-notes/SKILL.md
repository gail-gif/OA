# Deal notes: Notion card + GHL paste block

Read the `oa-basics` skill first. Gail's CRM is **GHL, not HubSpot**. GHL is **not connected**, so always produce text she can paste.

## 1. Gather
Fathom call(s) (summary + transcript), the JD or proposal in Google Drive, and recent emails.

## 2. Answer Gail's deal questions
JD • Package • Pricing • Proposal • Shift dates and time (client time + PHT) • Communication tool • Next meeting.
Flag mismatches, e.g. the JD says full-time but the call said part-time, or the proposal link is the same file as the JD.

## 3. GHL opportunity (paste block)
- Name: `<Client Name>_<PT/FT> <Role type>_<Service Offering> (<discount note>)`, e.g. "May Ly_PT Specialist_Angel Accelerate (no discount)".
- Pipeline: OA Client. Stage, e.g. Proposal Sent / Awaiting Deposit.
- Fields: Email, Phone, Source (Organic / Referral (Linh) / Scott X100 / BDM …), Deal Type (e.g. PT Tech), Service Offering, Primary Pain Point (e.g. Hiring Challenge), Proposal Sent date, value.
- Note titled **"Freedom Audit Summary"**: Call (date, Fathom link) • Business • Role (tasks, tools) • Hours • Pricing discussed • Why us • Next steps • Proposal sent.

## 4. Notion Sales Calendar card
- Status: Lead - Pending Decision after a proposal.
- Discovery Call Outcome, e.g. Connected & Qualified.
- Proposal code: PT ADV / FT ADV / PT Specialist … If there's no matching option, pick the closest and say so.
- Also fill: Sales Deal summary; Notes / Status starting with the date; Industry, Country, Original Source.
- Page body: Deal Summary, call notes, Fathom link and a Next steps checklist.

Gail confirms with "all is correct" before you write to Notion.
